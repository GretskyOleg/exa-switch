# EXA Switch — быстрый старт для чайников

Эта инструкция для тех, кто впервые ставит EXA Switch. Никаких терминалов,
если ты на Windows — просто мышкой.

> **Что такое EXA Switch?** Это расширение для браузера + маленькая программа
> helper. Расширение говорит браузеру «этот сайт — через туннель», а helper
> держит сам туннель. Всё работает только в браузере, системный VPN не нужен.

> **Что такое `vless://`?** Это ссылка на твой сервер, её даёт VPN-провайдер
> или админ. Она длинная и начинается с `vless://`. Без неё расширение ничего
> проксировать не будет.

## Windows: 5 шагов

### 1. Скачай установщик

Открой страницу релиза:

**https://github.com/GretskyOleg/exa-switch/releases/latest**

Скачай файл:

- `EXA-Switch-Setup-windows-amd64.exe` — обычный Windows (почти у всех);
- `EXA-Switch-Setup-windows-arm64.exe` — только если у тебя Windows на ARM.

### 2. Запусти

Двойной клик по файлу.

Если Windows покажет синее окно **«Windows protected your PC»**:

1. Нажми **More info** / **Подробнее**.
2. Нажми **Run anyway** / **Выполнить в любом случае**.

Это нормально: установщик не подписан платным сертификатом.

### 3. Выбери браузер

В чёрном окне установщик покажет список:

```
Обнаружены браузеры:
  1) Firefox
  2) Google Chrome
  3) Microsoft Edge

Куда установить расширение? [1,2 / all / none] (Enter = Firefox, если есть):
```

- Хочешь **только Firefox** — просто нажми **Enter**.
- Хочешь Firefox и Chrome — напиши `1,2` и нажми Enter.
- Хочешь во все — напиши `all`.

Если браузера нет в списке — значит он не найден. Можно поставить позже
вручную (см. «Если что-то не так»).

### 4. Перезапусти браузер

Закрой Firefox (или Chrome) полностью и открой заново.

### 5. Включи расширение

1. В Firefox нажми на иконку **пазла** (справа сверху).
2. Найди **EXA Switch** и нажми на него.
3. Чтобы иконка была всегда под рукой: правый клик по ней → **Закрепить на панели**.

Теперь добавь сервер:

1. Нажми на иконку **EXA Switch** → **шестерёнка** (настройки).
2. В большое поле вставь ссылку `vless://...`.
3. Нажми **Импортировать**.
4. Подожди пару секунд — появится «Туннель работает».
5. Выбери режим **Авто**.

Готово. Теперь открой нужный сайт, нажми на иконку EXA Switch и выбери
**Прокси**. Сайт пойдёт через туннель. Остальные сайты — напрямую.

## Linux (Arch / CachyOS): 4 шага

### 1. Скачай пакет

Со страницы релиза скачай:

```
exa-switch-0.1.2-1-x86_64.pkg.tar.zst
```

### 2. Установи

Открой терминал в папке с файлом и выполни:

```bash
sudo pacman -U exa-switch-0.1.2-1-x86_64.pkg.tar.zst
```

### 3. Перезапусти Firefox

Расширение уже установлено пакетом. Просто закрой и открой Firefox.

### 4. Добавь `vless://`

1. Иконка **пазла** → **EXA Switch** → закрепить.
2. Шестерёнка → вставь `vless://...` → **Импортировать**.
3. Режим **Авто**.

**Chrome / Chromium / Edge / Brave / Vivaldi на Linux** — по желанию:

```bash
xray-switch-browsers install all
```

Потом перезапусти браузер.

## Если что-то не так

### «Helper не доступен»

1. Перезапусти браузер полностью (не просто вкладку).
2. Если не помогло — запусти установщик ещё раз (он переустановит helper).
3. На Linux проверь:

```bash
systemctl --user status xray-switch
```

### Не вижу иконку расширения

Нажми на иконку **пазла** в браузере. Если EXA Switch там есть — закрепи его.
Если нет — перезапусти браузер ещё раз.

### Сайт с «Прокси» не открывается

Открой настройки расширения → вкладка **Helper и логи** → нажми **Проверить**.
Там будет написано, что именно не так. Частая причина — неправильная или
просроченная `vless://`-ссылка.

### Chrome не подхватил расширение

1. Открой `chrome://extensions`.
2. Включи **Developer mode**.
3. Нажми **Load unpacked**.
4. Выбери папку:
   - Windows: `%LOCALAPPDATA%\xray-switch\extension\chrome`
   - Linux: `/opt/xray-switch/extension/chrome`

### Хочу убрать расширение из Chrome

Windows: запусти установщик ещё раз и выбери только Firefox (Enter).
Linux:

```bash
xray-switch-browsers remove chrome
```

### Как удалить всё

- Windows: `EXA-Switch-Setup-windows-amd64.exe --uninstall` или Параметры → Приложения.
- Linux: `sudo pacman -R exa-switch`.
- Настройки/логи остаются в `%APPDATA%\xray-switch` (Windows) или
  `~/.config/xray-switch` (Linux). Их можно удалить вручную.

## Совсем коротко

1. Скачай установщик.
2. Запусти → Enter (Firefox).
3. Перезапусти Firefox.
4. Вставь `vless://...` в настройках расширения.
5. Режим **Авто** → на нужном сайте нажми **Прокси**.

Всё.
