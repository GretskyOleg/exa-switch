EXA Switch — установка
======================

> Если установлен пакет Arch/CachyOS (`exa-switch-*.pkg.tar.zst`), расширение
> Firefox уже установлено автоматически, а helper работает как systemd
> user-служба. Этот файл — для portable-установщика и сборки из исходников.

Установщик уже сделал всё, что можно сделать без прав администратора:

  • поставил локальный helper с xray-core;
  • прописал native messaging для Chrome / Chromium / Edge / Brave / Firefox;
  • распаковал расширение и открыл страницу с инструкцией.

Осталось добавить расширение в браузер — это ограничение Chrome и Firefox,
а не установщика. Браузеры не разрешают программе молча поставить расширение
из локальной папки.

Chrome / Chromium / Edge / Brave
--------------------------------
1. Открой  chrome://extensions
2. Включи Developer mode (режим разработчика).
3. Нажми Load unpacked / Загрузить распакованное.
4. Выбери папку с расширением (путь есть на странице установки).
5. Готово. Chrome запомнит расширение после перезапуска.

Firefox
-------
1. Открой  about:debugging#/runtime/this-firefox
2. Load Temporary Add-on.
3. Выбери manifest.json из папки расширения.
4. Temporary Add-on исчезает после перезапуска Firefox.
   Для постоянной установки нужен подписанный XPI (AMO) или Firefox
   Developer Edition / Nightly с отключённой проверкой подписи.

После установки расширения
--------------------------
1. Открой настройки расширения.
2. Вставь vless://... и нажми «Импортировать».
3. Выбери профиль и режим «Авто».
4. Открой сайт → popup → «Прокси». Или добавь домены в «Правилах».

Проверка
--------
На странице установки и в настройках расширения есть кнопка «Проверить».
Она делает HTTPS-запрос через локальный SOCKS и показывает задержку.

Если helper не найден
---------------------
Перезапусти браузер (Chrome читает native messaging при старте) и нажми
«Перезапустить helper» в настройках расширения.

Удаление
--------
Linux/macOS:
  xray-switch-helper stop
  удали native messaging manifests и папку установки
  (или запусти установщик с --uninstall).

Windows:
  запусти установщик с параметром --uninstall
  (или удали приложение через параметры системы).
